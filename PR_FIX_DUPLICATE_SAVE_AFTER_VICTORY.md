# Pull Request Package

## Title

`fix: prevent duplicate leaderboard save after victory`

## Summary

- Исправлен баг, при котором после победы можно было повторно сохранить результат в leaderboard.
- Причина бага: после завершения партии игра не переходила в явное post-win состояние, поэтому повторные действия могли снова активировать победный сценарий.
- Изменены файлы:
  - `script.js`
  - `tests/e2e/smoke.spec.js`

## Technical changes

- В игровое состояние добавлен флаг `gameFinished`.
- При старте новой игры флаг сбрасывается.
- После победы:
  - таймер останавливается;
  - игра помечается как завершенная;
  - дальнейшие действия, ведущие к повторному завершению партии, блокируются.
- `gameStarted = false` после победы также осознанно закрывает смежный post-win кейс:
  кнопка подсказки больше не активирует действия после завершения партии.
- Выбран минимальный вариант исправления без крупного рефакторинга и без изменения публичных интерфейсов.

### Рассмотренные альтернативы

- Полный рефакторинг состояния игры в отдельную state machine.
  - Не выбран, потому что для текущего бага это избыточно по стоимости и риску.
- Блокировка только повторного `saveRecord()` без завершения состояния игры.
  - Не выбрана, потому что это оставляло бы игру в неконсистентном post-win состоянии.

### Regression now covered

Этот PR теперь покрывает регрессию:

- повторный клик после победы не создает вторую запись;
- счетчик ходов не меняется после завершения партии;
- leaderboard не получает дубликат результата;
- существующий победный сценарий остается рабочим;
- новая игра после победы корректно сбрасывает post-win состояние;
- клавиатурный ввод после победы не может повторно активировать сохранение.

## Risk assessment

### Потенциально затронутые сценарии

- победный сценарий с сохранением результата;
- старт новой игры после завершенной партии;
- поведение поля после победы;
- альтернативные действия после победы, включая клавиатуру и подсказку.

### Почему риск считается приемлемым

- изменение локальное и минимальное;
- новая логика ограничена post-win состоянием;
- `gameFinished` сбрасывается при `startGame()`;
- браузерный регрессионный контур подтверждает, что победа, новая игра и post-win блокировки работают корректно.

### Остаточный риск

- низкий.
