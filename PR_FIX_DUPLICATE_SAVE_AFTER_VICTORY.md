# Pull Request Package

## Title

`fix: prevent duplicate leaderboard save after victory`

## Summary

- Исправлен баг, при котором после победы можно было повторно сохранить результат в leaderboard.
- Причина изменения: после завершения партии игра не переходила в явное состояние "завершено", поэтому повторные действия могли снова активировать победный сценарий.
- Изменены файлы:
  - `script.js`
  - `tests/e2e/smoke.spec.js`

## Technical changes

- В игровое состояние добавлен флаг `gameFinished`.
- При старте новой игры флаг сбрасывается.
- После победы:
  - таймер останавливается;
  - игра помечается как завершённая;
  - дальнейшие клики по плиткам игнорируются.
- Выбран минимальный вариант исправления без крупного рефакторинга и без изменения публичных интерфейсов.

### Рассмотренные альтернативы

- Полный рефакторинг состояния игры в отдельную state machine.
  - Не выбран, потому что для текущего бага это избыточно по стоимости и риску.
- Блокировка только повторного `saveRecord()` без завершения состояния игры.
  - Не выбрано, потому что это оставляло бы игру в неконсистентном post-win состоянии.

- повторный клик после победы не создаёт вторую запись;
- счётчик ходов не меняется после завершения партии;

- существующий победный сценарий остаётся рабочим.

## Risk assessment

### Потенциально затронутые сценарии

- победный сценарий с сохранением результата;
- старт новой игры после завершённой партии;
- поведение поля после победы.

### Почему риск считается приемлемым

- изменение локальное и минимальное;
- новая логика ограничена post-win состоянием;
- `gameFinished` сбрасывается при `startGame()`;
- браузерный регрессионный контур подтверждает, что победа и новая игра работают корректно.
